# Moult Диск — Защищённая синхронизация ПК (Windows) и Android

**Moult Диск** — программа для синхронизации файлов между несколькими компьютерами под управлением Windows (**Главный домашний ПК** и **Рабочий ПК для слива файлов**) и смартфонами **Android** (включая папку `DCIM/Camera`).

Проект объединяет удобство **Яндекс.Диска** (системный трей Windows, быстрый доступ к папкам в Проводнике, лента последних файлов, Корзина и история версий) и гибкость **Dropsync** (выбор направления синхронизации для каждой заданной папки: *Двусторонняя*, *Только отправка / Слив*, *Только приём*).

---

## 1. Архитектура безопасности пересылаемых данных

В **Moult Диск** реализована 4-уровневая защита передаваемых и хранимых файлов:

1. **Взаимная криптографическая аутентификация устройств (mTLS 1.3):**
   * При первом запуске программа генерирует криптографическую пару ключей **ECDSA P-384** и сертификат **X.509** (`cert.pem`, `key.pem`).
   * Идентификатор устройства (`Device ID`) вычисляется как **SHA-256** отпечаток сертификата в кодировке Base32 с контрольными суммами **Luhn mod 32** (полная совместимость с протоколом Syncthing BEP).
   * Ни одно стороннее устройство в локальной сети или интернете не может подключиться или запросить список файлов без двустороннего подтверждения сертификатов.
2. **Сквозное шифрование файлов и сейфа (`AES-256-GCM`):**
   * Модуль `moult/security/crypto.py` реализует аутентифицированное шифрование **AES-256-GCM** с выводом ключа через **PBKDF2-HMAC-SHA256 (600 000 итераций)**, случайной 128-битной солью и 96-битным nonce.
   * Поддерживается шифрование отдельных конфиденциальных файлов (`.moultenc`) и папок.
3. **Зашифрованные токены сопряжения (`MOULT-PAIR-V1`):**
   * Для подключения Рабочего ПК к Главному домашнему ПК не нужно пересылать открытые конфигурационные файлы. Программа упаковывает параметры подключения и шифрует их вашим одноразовым PIN-паролем (`AES-256-GCM`).
4. **Контроль целостности `SHA-256` и защита от потери версий:**
   * Каждый переданный файл проверяется по потоковой контрольной сумме **SHA-256** до и после записи.
   * При обновлении или перезаписи файлов предыдущая копия автоматически сохраняется в **Корзину версий** с возможностью восстановления в 1 клик.

## 2. Предустановленные профили и папки

Программа поддерживает мгновенное переключение роли компьютера:

* **🏠 Главный ПК (Домашний — центр хранения):**
  * `01_Слив_с_Рабочего_ПК` — режим **Только приём (`receiveonly`)**: принимает файлы с работы в мастер-хранилище.
  * `02_Общие_Документы` — режим **Двусторонняя (`sendreceive`)**: синхронизирует рабочие документы между домом и офисом.
  * `03_Камера_Android` — режим **Только приём (`receiveonly`)**: принимает фотографии и видео из папки `DCIM/Camera` со смартфона.
  * `04_Обмен_с_Телефоном` — режим **Двусторонняя (`sendreceive`)**: быстрый обмен файлами с Android.
  * `05_Сейф_и_Базы_Данных` — режим **Двусторонняя + AES-256 + Process Guard**: защищённая папка с хранением 30 версий и защитой от копирования открытых баз данных.
* **💼 Рабочий ПК (Офис — слив файлов):**
  * Автоматически переводит папку `01_Слив_с_Рабочего_ПК` в режим **Только отправка (`sendonly`)**, чтобы безопасно сливать рабочие файлы на Главный домашний ПК.

## 3. Быстрый запуск на Windows

### Вариант А: Запуск в 1 клик (Windows Tray + GUI)
Дважды кликните по файлу **`start_windows.bat`**. Скрипт автоматически:
1. Создаст виртуальное окружение `.venv` и установит зависимости (`PySide6`, `cryptography`, `fastapi`, `uvicorn`, `psutil`, `qrcode`).
2. Скачает официальный бинарный движок `syncthing.exe` и проверит его цифровую контрольную сумму `SHA-256`.
3. Запустит программу с иконкой в системном трее Windows (около часов, как у Яндекс.Диска).

### Вариант Б: Сборка портативного `MoultDisk.exe` для переноса на второй ПК
Запустите **`build_windows_exe.bat`**. В папке `dist\MoultDisk\MoultDisk.exe` появится готовая сборка, не требующая установленного Python на втором ПК.

### Вариант В: Запуск из командной строки
```bash
# Нативный режим (Трей Windows + локальная панель управления)
python main.py --mode auto --port 8765

# Только веб-панель управления
python main.py --mode web --host 0.0.0.0 --port 8000

# Однократная синхронизация всех папок (например, для Планировщика задач Windows)
python main.py --mode sync-once
```

## 4. Подключение Android-смартфона

1. Откройте вкладку **«📱 2-й ПК и Android (QR)»** в программе на ПК.
2. На этапе до сборки собственного APK вы можете сразу установить на Android бесплатный открытый клиент **Syncthing-Fork** и отсканировать QR-код с экрана ПК — устройства соединятся напрямую по протоколу **TLS 1.3 (BEP)**.
3. Следующим этапом поверх этого же протокола и токенов `MOULT-PAIR-V1` собирается специализированное Android-приложение (APK) с автовыгрузкой папки `DCIM/Camera`.
